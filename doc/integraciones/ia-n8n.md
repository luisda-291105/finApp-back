# IA y n8n

## Papel de la IA

La IA interpreta y automatiza: interpretar mensajes, extraer información,
clasificar contenido, detectar contexto, identificar entidades, relacionar
información, determinar prioridades, procesar correos y mensajes, aplicar criterios
personalizados.

La IA no trabaja sin contexto: FinApp le proporciona información estructurada
sobre usuario, personas, grupos, organizaciones, servicios, categorías,
relaciones, historial, preferencias y permisos.

## Aprendizaje mediante correcciones

El usuario corrige clasificaciones y la corrección se convierte en preferencia:

```text
IA:      Netflix → Entretenimiento → No importante
Usuario: Netflix → Entretenimiento → Importante
```

Así FinApp se adapta progresivamente a cómo cada persona organiza su información.

## n8n

n8n ejecuta las automatizaciones: filtrado de correos, clasificación, detección de
contexto, identificación de remitentes, triggers, actualización de información y
comunicación entre servicios.

```text
Fuente → n8n → Validaciones → IA → Clasificación → FinApp → Base de datos → Dashboard
```

La aplicación verifica posteriormente que la automatización produjo el resultado
esperado.
